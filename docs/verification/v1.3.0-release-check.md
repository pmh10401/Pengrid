## Verification boundaries

The GitHub stable-channel label is not Developer ID trust, Apple notarization,
Gatekeeper acceptance, or completion of all physical-manual gates.
Full physical-pointer/multi-display, signed-in Drive/OneDrive, VoiceOver and
external/case-sensitive-volume checks were not newly run for build 14.
Their unperformed scenarios remain unqualified in the existing checklists.

The four [native screenshots](../images/README.md) show the unchanged Preview 11
UI with synthetic data; they are not new physical-device qualification.
Eleven existing SwiftPM fixture warnings and the existing minizip C conversion
warning remain. Unsigned mode did not generate a new ZIP; no preserved ZIP
should be uploaded as a build-14 artifact.

CI and anonymous public-download checks occur after this local packaging record.
Their final status must be read from the release PR/run and uploaded asset, not
inferred from this document. Publication must target the tested merge tree and
match the package's production inputs.
