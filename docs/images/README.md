# Pengrid screenshots

Captured on 2026-10-06 from the native Preview 11 feature candidate.

| Image | Contents |
| --- | --- |
| `workspace.png` | Production `WorkspaceView` with two real directories containing synthetic project files. |
| `notch-shelf.png` | Production horizontal `ShelfView`, Dark Glass, five manually added sample items. |
| `side-shelf.png` | The same shelf and selection docked on the right, with vertical cards and fixed controls. |
| `shelf-settings.png` | Production Korean settings from the installed candidate; no account or file contents. |

The first three images were captured through native computer control using an
isolated presentation host linked against Pengrid's production module. Its
preferences, favorites, cloud-location registry and shelf storage were separate
from the installed app. Files and notes are synthetic. The penguin image is
the existing Pengrid app icon. The settings image comes from the installed app.
No user clipboard content or signed-in cloud account was imported or published.

These are unretouched window captures, not rendered design mockups. Native glass
appearance varies with macOS, the desktop background and accessibility settings.
The release build number was subsequently incremented to 13 without changing
the pictured UI. See [README](../../README.md) and [한국어](../../README.ko.md).
