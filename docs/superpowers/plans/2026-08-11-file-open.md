# File Open Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a discoverable **Open** action to the file-table context menu and route the complete selection through Pengrid's existing safe file-opening pipeline.

**Architecture:** `FileTableView` will expose a multi-item callback only for context-menu opening while retaining its single-item double-click callback. `FilePaneView` will feed both callbacks into one array-based helper that calls `WorkspaceOpenActions` exactly once, preserving the existing folder, package, cloud materialization, and identity-verification behavior.

**Tech Stack:** Swift 6, SwiftUI, AppKit `NSTableView`/`NSMenu`, Swift Testing, Swift Package Manager, macOS 15+

## Global Constraints

- Use `WorkspaceOpenActions` as the only authority for navigation, cloud preparation, and external opening.
- Ordinary directories navigate in the active pane; files, applications, and packages open through macOS.
- Do not directly execute shell scripts or Unix binaries as child processes.
- Do not bypass macOS quarantine, Gatekeeper, scoped access, materialization, cancellation, or identity validation.
- Disable **Open** while text editing is active or when the selection is empty.
- Preserve the existing double-click and Command-O behavior.

```swift
@Test func contextMenuOpenRoutesTheStableTableOrderSelection() throws {
    let directory = URL(filePath: "/tmp/table-open", directoryHint: .isDirectory)
    let first = makeTableItem(named: "first.txt", in: directory)
    let middle = makeTableItem(named: "middle.txt", in: directory)
    let last = makeTableItem(named: "last.txt", in: directory)
    let selection = SelectionRecorder(value: [last.url, first.url])
    var opened: [FileItem] = []
    let view = FileTableView(
        items: [first, middle, last],
        selection: selection.binding,
        onActivatePane: {},
        onOpen: { _ in },
        onOpenSelection: { opened = $0 },
        onSortChange: { _ in }
    )
    let coordinator = view.makeCoordinator()
    let scrollView = view.makeScrollView(coordinator: coordinator)
    let tableView = try #require(scrollView.documentView as? NSTableView)
    coordinator.apply(items: view.items, selection: selection.value, to: tableView)
    let menu = try #require(tableView.menu)

    coordinator.menuNeedsUpdate(menu)
    let openItem = try #require(menu.items.first { $0.title == "Open" })
    #expect(openItem.isEnabled)
    #expect(NSApp.sendAction(openItem.action!, to: openItem.target, from: openItem))

    #expect(opened == [first, last])
}
```

At the start of `menuNeedsUpdate(_:)`, after constructing `policy`, add **Open** before the creation actions:

```swift
addMenuItem("Open", action: #selector(openFromMenu), enabled: policy.canOpen, to: menu)

```

Add the selector beside the existing context-menu selectors:

```swift
@objc private func openFromMenu() {
    let selectedItems = items.filter { parent.selection.contains($0.url) }
    parent.onOpenSelection(selectedItems)
}
```
