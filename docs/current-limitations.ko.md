# Pengrid 현재 제한 사항

**한국어** · [English](current-limitations.md) ·
[사용자 안내](user-guide.ko.md)

이 목록은 현재 소스 트리와 Developer Preview 7 DMG를 기준으로 합니다.

## 플랫폼과 배포

- Apple Silicon 및 macOS 15 이상만 지원합니다.
- 무료 공개 DMG는 ad-hoc 서명이며 Developer ID 서명이나 공증을 받지 않았습니다.
- Intel 빌드, Mac App Store 배포 및 자동 업데이트를 제공하지 않습니다.

## 검색, 미리보기 및 클라우드

- 검색은 기본적으로 이름, 상대 경로 및 사용 가능한 메타데이터를 사용합니다.
  선택 가능한 Spotlight 내용 검색은 이미 색인된 일반 문자열 내용만 사용하며,
  provider 위치·제외된 위치·미색인 위치에서는 범위가 불완전할 수 있습니다.
  스니펫이나 Pengrid의 영구 색인은 제공하지 않습니다.
- Get Info는 읽기 전용입니다. 이름, 태그, 권한, 소유권, 날짜 또는 확장 속성을
  바꾸지 않으며 SHA-256은 명시적인 단일 파일 작업으로만 제공합니다.
- 폴더 미리보기는 한 단계의 읽기 전용 기능입니다. 로컬에 공개되지 않은 File
  Provider 메타데이터는 자동 다운로드하지 않고 사용할 수 없음으로 표시합니다.
- Google Drive와 OneDrive는 macOS File Provider 루트를 사용합니다. Google 또는
  Microsoft OAuth/API 직접 클라이언트는 없습니다.
- 등록되지 않은 `~/Library/CloudStorage` 하위 위치는 변경 기능을 알 수 없으므로
  일괄 이름 변경을 fail closed 처리합니다.

## 일괄 이름 변경

- 활성 패널의 같은 상위 폴더에서 완전히 로드한 항목을 두 개 이상 선택해야
  합니다.
- 일반 문자열 찾기/바꾸기, 접두사, 접미사 및 일련번호 규칙만 지원합니다.
- 정규식, 하위 폴더 재귀 변경, 확장자 직접 편집, 행별 사용자 지정 이름 또는
  파일시스템 대소문자 정책의 사용자 강제 변경은 지원하지 않습니다.
- 일반 파일·패키지 확장자와 알려진 복합 압축 확장자는 의도적으로 보존합니다.
  확장자 자체를 바꾸려면 단일 항목 이름 변경을 사용해야 합니다.
- 변경은 직렬로 실행합니다. 롤백에 복구 검토가 필요하면 소유권을 추측하거나
  불확실한 항목을 삭제하지 않고 큐를 중지합니다.

## 폴더 동기화

- 최신 비교의 전체 범위를 검토한 뒤 한 방향으로 동기화할 수 있습니다.
  양방향 병합, 예약, 백그라운드 감시 또는 연속 동기화는 없습니다.
- 계획은 전부 적용하거나 적용하지 않습니다. 복사, 교체, 휴지통 행을
  따로 고를 수 없습니다.
- 완료된 동기화는 Undo로 되돌리거나 캡처한 검토로 다시 시도할 수 없습니다.
  실행 중 취소는 이 작업이 만든 변경만 되돌리거나 Recovery Needed를
  보고합니다.
- 심볼릭 링크, 패키지, 특수 항목, 종류/이름 충돌, 안전하지 않은 루트 관계는
  계획을 차단합니다. 검토나 트랜잭션을 위해 File Provider 항목을 내려받지
  않습니다.
- 대상에만 있는 항목은 게시 후 휴지통으로 보냅니다. 기존 사용자 데이터는
  영구 삭제하지 않습니다.

## 압축 및 파괴적 작업

- 네이티브 압축 도구는 형식 전체에 적용되는 신뢰할 수 있는 바이트 진행률을
  제공하지 않습니다.
- 7z, RAR 및 암호로 보호된 TAR은 지원하지 않습니다.
- AES ZIP 호환성은 fixture로 검증하며 Finder와 Archive Utility는 AES ZIP을 열지
  못할 수 있습니다. 리소스 포크, ACL 및 확장 속성의 왕복은 보장하지 않습니다.
- 검토한 항목은 휴지통으로 보내며 영구 삭제하지 않습니다.
- 소유권 또는 동일성을 증명할 수 없으면 자동 정리하지 않습니다.
