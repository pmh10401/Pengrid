# Pengrid 현재 제한 사항

**한국어** · [English](current-limitations.md) ·
[사용자 안내](user-guide.ko.md)

이 목록은 현재 소스 트리와 Developer Preview 7 DMG를 구분해 설명합니다. 전송
내용 검증과 명시한 다른 소스 전용 작업 흐름은 마지막 공개 DMG에 포함되어 있지
않습니다.

## 플랫폼과 배포

- Apple Silicon 및 macOS 15 이상만 지원합니다.
- 무료 공개 DMG는 ad-hoc 서명이며 Developer ID 서명이나 공증을 받지 않았습니다.
- Intel 빌드, Mac App Store 배포 및 자동 업데이트를 제공하지 않습니다.

## 검색, 미리보기 및 클라우드

- 검색은 기본적으로 이름, 상대 경로 및 사용 가능한 메타데이터를 사용합니다.
  선택 가능한 Spotlight 내용 검색은 이미 색인된 일반 문자열 내용만 사용하며,
  provider 위치·제외된 위치·미색인 위치에서는 범위가 불완전할 수 있습니다.
  스니펫이나 Pengrid의 영구 색인은 제공하지 않습니다.
- Get Info는 읽기 전용입니다. 이름, 태그, 권한, 소유권, 날짜 또는 확장 속성을
  바꾸지 않으며 SHA-256은 명시적인 단일 파일 작업으로만 제공합니다.
- 폴더 미리보기는 한 단계의 읽기 전용 기능입니다. 로컬에 공개되지 않은 File
  Provider 메타데이터는 자동 다운로드하지 않고 사용할 수 없음으로 표시합니다.
- Google Drive와 OneDrive는 macOS File Provider 루트를 사용합니다. Google 또는
  Microsoft OAuth/API 직접 클라이언트는 없습니다.
- 등록되지 않은 `~/Library/CloudStorage` 하위 위치는 변경 기능을 알 수 없으므로
  일괄 이름 변경을 fail closed 처리합니다.

## 생산성 작업 흐름

> 이 절의 생산성 작업 흐름은 현재 소스 트리를 설명합니다. 이 기능이 기존
> Developer Preview 7 DMG에 포함되어 있다는 뜻은 아닙니다.

- **Quick Go…**는 현재 scene에만 연결된 열거형 기반의 타입 안전 팔레트입니다. 후보는 안전한 고정
  명령(**Create Folder**, **Create File**, **Show Filter**, **Smart Search**),
  활성 패널의 현재·뒤로·앞으로 위치, 사용할 수 있는 즐겨찾기, 작업 공간 프로필
  및 저장된 검색으로 제한됩니다. 매칭은 기존 한글 초성(Hangul-initial) 지원을
  포함한 정규화된 텍스트를 사용합니다. 스크립트를 실행하거나 색인을 크롤링하거나
  파일 콘텐츠를 materialize하지 않습니다.
- **New Empty File**은 **Option-Command-N**을 사용하며, 캡처한 부모 디렉터리
  동일성에 묶인 배타적·덮어쓰기 없는 일반 파일 생성을 수행합니다. 성공하면 새
  행을 선택하고 인라인 이름 변경을 시작하기 전에 패널을 새로 고칩니다. 보수적인
  Undo는 새 파일의 정확한 동일성과 지문이 유지되는 동안에만 사용할 수 있습니다.
  불러온 형제 항목과의 충돌은 `New File 2`, `New File 3`처럼 처리하며, 배타적
  공개 시점의 아직 보지 못한 경쟁 충돌만 실패합니다.
- **Select All Visible** (**Option-Command-A**), **Invert Selection**
  (**Option-Command-I**), **Select Same Extension**
  (**Option-Command-E**)은 활성 패널의 현재 표시된 필터링되지 않은 행을
  대상으로 합니다. 패널 필터나 텍스트 편집 중에는 비활성화됩니다. Select Same
  Extension은 실제 확장자가 있는 표시된 일반 파일 하나만 선택해야 합니다.
- Finder 태그 편집은 제공하지 않으며 Get Info는 읽기 전용입니다. 선택 가능한
  전송 내용 검증은 현재 소스에 구현되어 있지만 Developer Preview 7 DMG에는
  없습니다.

## 현재 소스의 전송 내용 검증

- 전역 설정의 기본값은 꺼짐입니다. 복사, Duplicate, 다른 볼륨으로 이동, 검토된
  동기화의 복사·교체를 지원합니다. 압축 생성·해제와 같은 볼륨의 이름 변경 방식
  이동은 대상이 아닙니다.
- SHA-256은 일반 파일의 데이터 포크를 검증합니다. 재귀 구조와 심볼릭 링크
  payload도 확인하지만 리소스 포크, 확장 속성, ACL, 소유권, 플래그, 생성일,
  하드 링크 관계 및 sparse allocation은 제외합니다.
- 한 작업의 파일 쌍 작업자는 최대 두 개입니다. 루트가 하위 항목 250,000개 또는
  깊이 256을 넘으면 검증을 켠 상태에서 안전하게 실패합니다.
- File Provider 콘텐츠는 읽을 수 있는 로컬 바이트를 제공해야 하며 다시
  materialize될 수 있습니다. Google Drive와 OneDrive 검증은 설치된 provider에서
  관찰할 때까지 수동 릴리스 게이트입니다.
- 영수증은 게시 직전에 다시 확인하지만 마지막 검증과 이름 공간 syscall을 하나의
  원자적 콘텐츠 잠금으로 만들 수 없습니다. 짧은 경쟁 구간이 남습니다.
- 정리 소유권을 증명할 수 있으면 실패 시 원본과 기존 대상을 보존합니다. 정리가
  불확실하면 검증하지 않은 항목을 지우지 않고 Recovery Needed로 전환합니다.

## 일괄 이름 변경

- 활성 패널의 같은 상위 폴더에서 완전히 로드한 항목을 두 개 이상 선택해야
  합니다.
- 일반 문자열 찾기/바꾸기, 접두사, 접미사 및 일련번호 규칙만 지원합니다.
- 정규식, 하위 폴더 재귀 변경, 확장자 직접 편집, 행별 사용자 지정 이름 또는
  파일시스템 대소문자 정책의 사용자 강제 변경은 지원하지 않습니다.
- 일반 파일·패키지 확장자와 알려진 복합 압축 확장자는 의도적으로 보존합니다.
  확장자 자체를 바꾸려면 단일 항목 이름 변경을 사용해야 합니다.
- 변경은 직렬로 실행합니다. 롤백에 복구 검토가 필요하면 소유권을 추측하거나
  불확실한 항목을 삭제하지 않고 큐를 중지합니다.

## 폴더 동기화

- 최신 비교의 전체 범위를 검토한 뒤 한 방향으로 동기화할 수 있습니다.
  양방향 병합, 예약, 백그라운드 감시 또는 연속 동기화는 없습니다.
- 계획은 전부 적용하거나 적용하지 않습니다. 복사, 교체, 휴지통 행을
  따로 고를 수 없습니다.
- 완료된 동기화는 Undo로 되돌리거나 캡처한 검토로 다시 시도할 수 없습니다.
  실행 중 취소는 이 작업이 만든 변경만 되돌리거나 Recovery Needed를
  보고합니다.
- 심볼릭 링크, 패키지, 특수 항목, 종류/이름 충돌, 안전하지 않은 루트 관계는
  계획을 차단합니다. 검토나 트랜잭션을 위해 File Provider 항목을 내려받지
  않습니다.
- 대상에만 있는 항목은 게시 후 휴지통으로 보냅니다. 기존 사용자 데이터는
  영구 삭제하지 않습니다.

## 압축 및 파괴적 작업

- 네이티브 압축 도구는 형식 전체에 적용되는 신뢰할 수 있는 바이트 진행률을
  제공하지 않습니다.
- 7z, RAR 및 암호로 보호된 TAR은 지원하지 않습니다.
- AES ZIP 호환성은 fixture로 검증하며 Finder와 Archive Utility는 AES ZIP을 열지
  못할 수 있습니다. 리소스 포크, ACL 및 확장 속성의 왕복은 보장하지 않습니다.
- 검토한 항목은 휴지통으로 보내며 영구 삭제하지 않습니다.
- 소유권 또는 동일성을 증명할 수 없으면 자동 정리하지 않습니다.
